# 매칭 흐름 디자인 비교

매물관리의 펼친 매칭 영역을 비교하는 독립된 React/Vite 페이지입니다. 실제 앱의 라우트·API·인증을 사용하지 않습니다.

## 실행

desktop 개발 서버(`pnpm dev:desktop`, 기본 5174)가 실행 중일 때 엽니다. 개발 서버의 기준 폴더는 `src/renderer`이므로, 그 밖에 있는 이 페이지는 파일 경로로 엽니다(`/@fs` 뒤에 이 폴더의 절대 경로):

http://localhost:5174/@fs/<저장소 경로>/apps/desktop/prototypes/matching-flow/index.html

서버가 꺼져 있다면 저장소 루트에서 `pnpm dev:desktop`으로 앱과 함께 띄웁니다. 개발 서버만 띄우려면 `pnpm --filter @estate-erp/desktop exec electron-vite dev --rendererOnly`를 씁니다.

별도 Electron 데모 창:

```sh
./node_modules/.bin/electron apps/desktop/prototypes/matching-flow/preview.cjs
```

## 비교 방향

1. **한눈에 비교** (`?v=1`): 공통 단계 머리글과 고객별 진행 점. 많은 고객의 위치 비교에 유리하고, 상세 작업은 행을 선택해야 합니다.
2. **고객별 경로** (`?v=2`): 고객마다 전체 경로를 표시하고 그 아래 확인사항을 펼칩니다. 경로와 업무가 직접 연결되지만 세로 공간을 더 씁니다.
3. **단계별 처리** (`?v=3`): 고객 목록과 단계별 작업 영역을 나눕니다. 한 고객의 업무 처리에 유리하고 여러 고객의 흐름을 동시에 비교하기는 어렵습니다.

하단 선택기 또는 1/2/3, 좌우 화살표로 전환합니다. R 또는 처음부터 버튼으로 초기화합니다. 각 안은 전환할 때 같은 데이터로 다시 시작하며 새로고침 후에도 수정 상태를 저장하지 않습니다.

## 체험 가능한 동작

- 고객 검색, 종료 고객 접기/보기, 매칭 영역 접기/펼치기
- 단계 미리보기, 체크 항목 확인 후 한 단계씩 이동
- 방문 일정 입력, 메모 편집/저장, 진행 이력 펼치기
- 사유를 선택해 매칭 종료, 멈췄던 단계에서 재개
- 준비된 두 명의 예시 고객 연결
- 거래전환 후 거래 준비 예시 보기

모든 이름·조건·이력은 데모용입니다. 단계별 체크 항목은 UX 제안이고 서버 규칙에 추가되지 않습니다. 방문 일정은 선택이며, 종료는 독립된 결과로 저장해 멈춘 단계를 유지합니다. 실제 전화·문자·일정·거래·고객 데이터는 만들거나 변경하지 않습니다.

프로덕션에서 이 페이지를 import하지 않습니다. 채택 전에는 이 폴더 안에서만 수정하세요.

## 2번 단일 HTML

`docs/mockups/matching-path-v2.html`은 고객별 경로만 담은 독립 파일입니다. CSS·폰트·JavaScript를 내장해 개발 서버나 인터넷 연결 없이 열 수 있습니다. 수정 내용은 새로고침하면 초기화됩니다.

저장소 루트에서 `node apps/desktop/prototypes/matching-flow/export-html.mjs`로 다시 내보냅니다. 독립 Electron 창에서 실제 `file://` 파일을 열어 화면, 상세 펼치기, 체크 후 단계 진행, 메모 저장, 일정 빠른 선택을 확인했습니다. 외부 HTTP 리소스 요청과 페이지 오류는 없었으며, 캡처는 `screenshots/02-standalone.png`입니다.

## 검증 (2026-11-13)

- 독립 Electron 창(CDP 9345)에 agent-browser로 연결해 세 안을 직접 전환하고 캡처했습니다. 실제 ERP 창의 통합 테스트는 아닙니다.
- 단계별 확인 항목에 따른 진행 버튼 활성화, 다음 단계 이동, 메모 저장, 일정 빠른 선택 후 단계 이동 시 유지, 종료 사유 선택, 같은 단계에서 재개를 확인했습니다.
- 예시 고객 연결 시 고객 수 5 → 6 반영, 검색 결과 없음, 거래전환 후 거래 준비 미리보기를 확인했습니다.
- 1/2/3·좌우 키 전환, 입력 중 숫자 키로 안이 바뀌지 않는 동작, URL 선택 상태, 한 개의 활성 선택기를 확인했습니다.
- 1580px 및 1180px 화면 확인. 최종 새로고침 뒤 콘솔 오류·페이지 오류 없음. 새 프로토타입 파일 TypeScript 검사 통과.
- 최종 초기 화면은 `screenshots/01-comparison.png`, `02-paths.png`, `03-workbench.png`입니다.
