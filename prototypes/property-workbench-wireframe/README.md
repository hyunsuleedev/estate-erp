# 매물관리 현행 구조 개선 HTML 데모

`/properties` 운영 화면의 정보 구조와 사용 흐름을 유지하면서 시각적 위계만 개선한 독립 HTML 와이어프레임이다. 운영 애플리케이션 코드는 사용하거나 변경하지 않는다.

## 담은 구조

- 거래 탭 → 단지·동·호·통합검색 → 목록·지도 → 새 매물 등록
- 지역·유형·매물상태·가격·월세·면적·입주일·광고 상시 필터
- `작업` 뒤에서 접고 펴는 `타입–확인` 보조 컬럼
- 같은 스크롤 컨테이너를 쓰는 컬럼 가이드 선과 테이블
- 매칭·광고 셀의 전체 폭 인라인 확장
- 행 더블클릭으로 열리는 기존 방식의 720px 상세 Sheet
- 목록과 지도 보기 전환

## 실행

저장소 루트에서:

```bash
pnpm exec vite prototypes/property-workbench-wireframe --host 127.0.0.1 --port 4176
```

그런 다음 `http://127.0.0.1:4176/`을 연다.
