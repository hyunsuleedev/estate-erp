### 코드에서 확인한 동작 연결 — 정적 관측

1. **표 선택 상태를 공유한다.** `tableSelectionOverlayActions`의 `handleDirection`은 행·열의 시작/끝 위치를 가진 선택 상태와 보이는 속성 목록을 받는다. 방향 및 Shift/Cmd/Ctrl 상태에 따라 다음 선택을 계산한 뒤 스크롤을 맞춘다. 포맷된 사본 591행부터.
2. **Enter 편집과 페이지 열기를 나눈다.** `handleEnter`는 선택한 속성 타입과 편집 가능 여부를 보고 셀 편집기를 열거나 체크박스 값을 처리한다. `handleCommandEnter`는 선택 행의 페이지 URL을 얻어 이동하는 별도 함수다. 사본 680–765행, export 연결 1439행부터. 체크박스 값 변경은 실제 실행하지 않았다.
3. **복사도 같은 선택 범위를 사용한다.** `handleCopy`는 표 선택, 행 목록, 보이는 속성 목록, 스키마를 공통 복사 처리로 전달한다. 사본 879행부터. 이번 조사에서 사용자 클립보드를 읽거나 덮어쓰지 않았다.
4. **선택·편집·페이지 열기의 연결을 UI 층에서 확인했다.** `CollectionViewBlock` 사본 28266행부터 키 입력을 `TableSelectionOverlay`에 모으고, Enter/Tab/방향키/복사/Command+Enter를 별도 처리에 연결한다. 셀 렌더링은 속성 타입을 다루는 `BlockPropertyRouter`로 전달된다(26468행 부근).
5. **선택 표시는 내용과 분리되어 있다.** 같은 사본 26420행 부근에서 셀 선택 배경과 안쪽 테두리를 포인터 이벤트 없는 별도 레이어로 만든다. 이것만으로 성능 우위를 주장하지 않는다.

여기서 가져올 핵심은 특정 React 코드의 복제가 아니라 **선택한 셀을 기준으로 조작을 일관되게 연결하는 구조**다.

## 1차 적용 결과 — 2026-11-12

로컬 Electron 매물관리 표에 다음 내용을 적용했다.

- 단지 셀의 상세 열기 버튼. 행 호버·키보드 포커스에서 아이콘과 `열기` 문구가 함께 나타나며 기존 사이드 패널을 연다.
- 열 제목 메뉴: 오름차순/내림차순/정렬 해제, 지원되는 기존 필터 열기, 해당 열까지 연속 고정, 고정 해제, 열 숨기기. 단지·의뢰 메모에는 내용 줄바꿈도 제공한다.
- 상단 컬럼 설정에서 전체 15개 데이터 열의 표시 상태 확인·변경 및 기본 표시 복원. 단지 열은 상세 열기의 기준 열로 유지한다.
- 상단 정렬 표시에서 현재 기준·방향 확인, 기준 변경, 방향 변경, 해제. 서버가 지원하는 기존 단일 정렬을 사용한다.
- 열 숨김 상태에 맞춰 키보드 이동, 빈 결과/확장 행의 colspan, 고정 열 위치와 `+/-` 묶음 선을 계산한다. 메뉴와 편집기의 키 입력을 표 탐색이 가로채지 않는다.

저장된 업무 보기와 셀 편집/복사 단축키 전면 개편은 후속 제안으로 남아 있다. 이번 열 표시·고정·줄바꿈 설정은 현재 표 세션에 적용되며 재시작 후 저장하는 기능은 추가하지 않았다.

### 검증

실행 중인 실제 Electron의 매물관리 탭에서 agent-browser snapshot/click/fill/press/screenshot으로 확인했다.

- 가격 내림차순 및 오름차순: 머리글 방향, 상단 요약, 실제 행 순서가 함께 바뀜.

### 열기 버튼 재조정 — 2026-11-12

사용자 피드백에 따라 Notion의 현재 표에서 버튼과 외곽 컨테이너의 계산된 스타일을 다시 측정했다. 외곽 55.02×24px, padding 2px, radius 6px, 흰색 배경과 얕은 외곽 그림자. 안쪽 버튼은 높이 20px, 12px/500 글자, 간격 6px, 좌우 padding 4px, radius 4px다. 오른쪽 면이 채워진 패널 아이콘을 단순 SVG 도형으로 재현했다.

실제 Electron에서 동일한 55.02×24px 크기와 글자색·간격을 확인했다. 평소 버튼 전체가 숨겨지고 행 호버 또는 키보드 포커스로 나타난다. 셀 안에 절대 배치해 전후 단지명 영역의 위치·폭이 변하지 않는다. 클릭 및 키보드 Enter로 각각 해당 행 상세가 열리는 것을 확인했고 타입 검사도 통과했다.
