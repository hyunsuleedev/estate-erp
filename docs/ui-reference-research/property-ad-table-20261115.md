## 광고 행 선택

광고에도 구매고객과 공유하는 `PropertyPanelSelectionCheckbox`를 적용했다. 기존 36px 왼쪽 여백을 사용해 데이터 열 위치는 유지한다. 행 호버 시 체크박스를 보이고, 선택·키보드 포커스 시에는 계속 표시한다. 전체 선택은 열 제목 호버에는 반응하지 않으며 자신의 체크박스 영역에서만 나타난다. 선택된 광고는 옅은 파란 배경, 부분 선택은 전체 선택자의 중간 상태로 표시하고 상단에 선택 개수·선택 해제를 제공한다.

선택은 광고 ID와 해당 펼침 패널에 속한다. 정렬로 행 위치가 바뀌어도 유지하고, 탭 전환·패널 닫기 시 해제한다. 상위 매물과 구매고객 선택에는 영향을 주지 않으며 업무 데이터를 변경하지 않는다.

실제 Electron에서 개별 선택, 부분/전체 선택, 선택 해제, Tab·Space, 정렬 후 같은 광고의 선택 유지, 탭 전환 후 해제를 확인했다. 기본 opacity `[0,0,0]`, 열 제목 호버 `[0,0,0]`, 전체 선택 영역 호버 `[1,0,0]`, 첫 행 호버 `[0,0.7,0]`를 실측했다. TypeScript 및 공유 패널 회귀 검사 2개 통과. 검수 중 변경한 정렬 설정은 원래 값으로 복구했다.

## 광고 요청 업무·수동 변경·수동 추가

광고 탭의 기존 상단 줄에 세 버튼을 추가했다. 별도의 도구 모음 높이는 추가하지 않는다.

| 작업 | 대상과 저장 동작 |
| --- | --- |
| 광고 요청 | 선택한 여러 광고를 하나의 `Task(category=advertisement, status=pending)`로 등록. 조건 변경·재광고·종료 요청을 선택하고 광고별 금액을 편집한다. 미선택이면 현재 매물의 거래와 채널을 골라 신규 광고 등록 업무를 만든다. 실제 CP 실행은 이 버튼에서 하지 않는다. |
| 수동 변경 | 정확히 한 광고 선택 시 활성화. 광고 자체의 금액·상태·날짜·원문 주소·메모를 편집하고 실제 바뀐 필드만 PATCH. 기존 CP 출처·식별자·변경하지 않은 날짜의 시각 정밀도를 보존한다. |
| 수동 추가 | 광고가 없어도 진입 가능. 거래·채널·금액·날짜·원문·메모를 입력하고 `source=manual`로 생성. 같은 거래·채널의 활성 광고 중복은 차단한다. |

만원 정수·안전한 URL·날짜 순서를 검증한다. 월세 보증금 0원은 보존한다. 저장 중 입력·중복 제출·닫기를 막고 실패 시 폼과 입력값을 유지한다. 취소와 Escape는 저장 전 초안을 버리고, 저장 성공 시 관련 쿼리를 무효화하고 선택을 해제한다. 닫히는 애니메이션 동안 폼 내용은 유지하고 작업 버튼으로 포커스를 복귀한다.

검증: 순수 동작 검사 14개(신규 작업 8개 + 광고 표 6개), Desktop TypeScript 검사, `git diff --check` 통과. 실제 Electron에서 버튼 활성 조건, 폼 초기값, 다중 광고 업무, 광고 없는 매물의 추가·요청, 저장 오류 후 입력 보존, 재시도, 저장 중 Escape 차단을 확인했다. 수동 PATCH 실패/성공 재시도·다중 광고 업무 POST·수동 추가 POST 총 4회는 renderer fetch에서 모의 응답으로 차단하고 요청 본문을 검증했다. 수동 광고 저장의 실제 서버 반영 검증은 수행하지 않았다.

## 수동 변경 정정: 셀 직접 입력

사용자의 수동 변경 의도는 별도 편집창이 아니라 Notion처럼 표에서 값을 바로 입력하는 것이었다. 위의 수동 변경 버튼과 편집창 진입을 제거했다. 광고 요청과 수동 추가는 기존대로 유지한다.

- 가격·보증금·월세·메모·원문 주소 셀은 한 번 클릭해 기존 공용 `EditableCell`로 입력한다. Enter 또는 바깥 클릭 저장, Escape 취소, Tab 이동, 메모 Shift+Enter 줄바꿈을 사용한다.
- 상태는 검색 없는 칩 선택 메뉴, 등록일은 셀 옆 달력·날짜 입력기로 열린다. 원문 주소 편집과 별도 링크 열기 아이콘을 구분한다.
- 광고의 변경한 필드만 PATCH하며 부모 매물 조건·CP 출처·식별자는 바꾸지 않는다. 가격과 보증금은 거래 유형에 맞는 필드를 사용하고 월세는 월세 거래에서만 편집한다.
- 표 내부의 스크롤 영역이 편집 메뉴 높이 때문에 움직이지 않도록 공용 편집기에 선택적 body portal을 추가했다. 기존 소비자의 기본 스크롤 컨테이너 방식은 유지한다. 광고 팝업은 스크롤·리사이즈 시 셀 위치를 따라가고 기존 14px/450 글꼴을 유지한다.
- 마지막 행의 상태 메뉴에서도 패널 scrollTop=0, clientHeight=scrollHeight를 확인했다. 선택 메뉴를 열어도 위쪽 헤더가 밀리지 않는다.
