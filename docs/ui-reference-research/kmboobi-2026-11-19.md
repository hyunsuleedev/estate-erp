# KM부비 페이지별 조사

2026년 11월 19일 로그인된 Chrome의 사이드바에서 22개 메뉴를 식별했다. 배포 진입 파일 main-D24PxwuX.js에서 명시적 경로 45개를 대조하고 REA 6.8.0으로 진입 파일과 페이지 모듈 등 46개 파일을 정적 분석했다. 아래 설명은 별도 표시가 없으면 클라이언트 코드 기준이다. 상세·편집·운영자 페이지와 저장·전송·유료 생성의 실행 결과는 검증하지 않았다.

## 메뉴와 경로의 관계

사이드바의 나의 매물등록·공동중개매물·찜한 매물은 같은 목록을 다른 조건으로 연다. 개인홈피는 공개 HTML 주소로 열린다. 사용법·코인사용·뉴스는 이동 경로와 코드 내용을 확인했으며 모든 본문이 로딩된 상태까지 대조하지는 못했다.
