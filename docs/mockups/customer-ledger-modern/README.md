# 고객 원장 · Modern Desktop

`index.html`을 브라우저에서 직접 열어보세요. Electron 데스크톱 앱을 위한 독립 HTML 시안입니다. 외부 라이브러리나 서버가 필요하지 않습니다.

## 시각적 변경

이전 `customer-ledger-refined`의 고객 묶음·의뢰 행·열 구성과 정렬 동작을 유지했습니다.

- 차가운 중성색 바탕, 흰 원장, 네이비 기본 버튼
- 선택 상태와 정렬에는 절제된 블루, 내놓음에는 그린
- 고객 이니셜과 이름으로 묶음의 시작을 구분
- 반복되는 세로선을 줄이고 예산·월세·평형 그룹의 경계만 유지
- 고객명·금액은 진하게, 연락처·상담·매물 조건은 보조 위계로 정리
- 탭·검색·필터·정렬 메뉴의 크기, 라운딩, 여백 통일
- 상담 창, 체크박스, 선택 행, 포커스까지 같은 시각적 언어 적용
- 모바일용 레이아웃 없이 데스크톱 창 너비에 대응

## 동작과 범위

정렬 메뉴, 열 제목의 3단계 정렬 및 해제, 마지막 정렬 기억, 검색, 지역·거래·상태·담당자·가격·평형 필터, 고객 접기/펼치기, 선택, 상담 기록, 새 구함 의뢰 추가가 포함됩니다. 상세한 예시 데이터와 정렬 집계 기준은 이전 시안과 같습니다.

고객 9명·의뢰 11건의 가상 데이터로 시작합니다. 저장 키는 `estait-ledger-modern-v1`과 `estait-ledger-modern-v1-sort`이며 이전 시안의 저장 내용과 분리됩니다. 주변 메뉴는 정적 미리보기, 매칭은 건수 요약입니다. CRM API 연결 및 실제 Electron 앱 반영은 하지 않았습니다.

## 이번 브라우저 검수

- 1440×960 전체 화면 및 상담 창 시각 검수
- 이름 정렬 선택 후 새로고침해도 정렬 유지
- 최대예산 열 내림차순 → 오름차순 → 정렬 해제 확인
- 김민준 검색 시 고객 1명과 의뢰 2건 함께 표시
- 고객 선택 체크박스·선택 행 표시, 접기·펼치기
- 상담 창 열기 및 Escape로 닫기
- 이민호 담당자 필터 결과 4명
- 1024×800에서 페이지·필터 넘침 없음
- 가로 스크롤 시 표 헤더·본문 열 정렬 일치, 정렬 메뉴 화면 내 표시

확인 결과는 독립 HTML을 Ego Browser에서 검수한 내용입니다.
