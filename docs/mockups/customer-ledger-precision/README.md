# Precision · Clean

Electron 고객원장의 디자인 방향을 검토하는 독립 HTML입니다. `index.html`을 브라우저에서 열면 됩니다. 실제 앱에는 반영하지 않았습니다.

- `1`: 기존 Precision / `2`: Precision · Clean
- 상단 ‘두 안 함께 보기’: 동일 너비로 위아래 비교
- 검색, 담당자 필터, 의뢰 유형, 예산 정렬(내림차순 → 오름차순 → 해제), 접기, 상담 메모, 매칭 요약을 조작할 수 있습니다.

## 디자인 방향

가벼운 탐색부와 흰 작업면, 짧은 조작부, 일정한 숫자 정렬로 업무 도구의 성격을 표현합니다. 고객명·매물·금액의 대비를 우선하고 고객마다 배경을 칠하는 패턴은 줄였습니다.

| 항목 | 기준 |
|---|---|
| 작업면 | #FFFFFF |
| 탐색부 | #F8F9FA |
| 기본 텍스트 | #23272E |
| 보조 텍스트 | #707985 |
| 구분선 | #E6E8EB |
| 주요 동작 | #303B4C |
| 선택 표시 | #52647E |
| 고객명 / 금액 / 보조 | 14px / 13px / 11–12px |
| 제목 / 조작 버튼 | 19px / 높이 32px |
| 반경 | 조작부 5px, 분류 표시 3px |
| 고객 헤더 / 의뢰 행 | 최소 48px / 32px, 보조 설명 별도 |

큰 그림자, 그라디언트, 반복 카드 대신 글자 굵기와 정렬로 위계를 만듭니다. 기존 Precision은 비교 기준으로 유지했습니다.

## 확인한 범위

- 브라우저 1440×1000 화면 확인, 1280×800 가로 넘침 없음.
- 고객 검색, 담당자 필터, 예산 3단계 정렬, 개별 접기·펼치기, 상담 창 열기, 두 안 비교 확인.
- 예시 데이터 5명·7개 의뢰. 검색·정렬·접기 상태는 비교 화면에서 공유됩니다.

## 한계

실제 Electron 동작 검증이나 서버 연결은 포함하지 않습니다. 임대 월세 등 원장의 모든 열을 구현한 화면은 아닙니다. 탐색 메뉴는 표시용이며, 매칭 버튼은 예시 건수만 보여줍니다. 상담 메모 저장은 브라우저 로컬 저장소에 현재 메모를 덮어쓰며, 실제 상담 이력 기능과 다릅니다. 공통 상단 ‘상담 기록’은 현재 검색 결과의 첫 고객을 엽니다. 이전 시안과 로컬 저장 키를 분리했습니다.
