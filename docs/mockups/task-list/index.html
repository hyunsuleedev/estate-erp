Linear "My issues"의 구조를 가져와 중개 업무에 맞게 바꿨습니다. 표의 열 제목을 없애고, 왼쪽은 우선순위·상태·제목, 오른쪽은 값이 있는 정보만 칩으로 붙입니다.
위쪽 탭은 "누구의 업무인지", 묶는 기준과 보이는 정보는 오른쪽 표시 메뉴로 옮겼습니다. 오늘은 2026년 11월 3일(화)로 가정합니다.

구현 전에 정할 것

  1. "AI 처리 중" 표시의 근거. 지금은 외부 AI가 광고 업무를 맡으면(claim) 상태가 진행중으로 바뀌고 담당자가 API 키 주인으로 채워질 뿐, AI가 맡았다는 기록이 업무에 남지 않습니다. 활동 기록(행위자 mcp)으로 판단하거나 업무에 "맡은 주체" 값을 하나 추가해야 합니다. → 처음엔 표시를 빼고 시작해도 됩니다.
  2. 카테고리 색. 지금 업무 화면은 "행마다 반복되는 값에는 색을 쓰지 않는다"는 원칙입니다. 시안은 칩 안의 작은 점에만 색을 씁니다. 원칙을 이렇게 조금 완화해도 될지 정해 주세요.
  3. 상태 탭을 없애도 되는지. 상태는 그룹 머리로 보이고, 완료는 기본으로 접힌 그룹(표시 메뉴에서 끌 수 있음), 취소된 업무는 필터의 상태 항목에서 골라 봅니다.
  4. 업무 번호는 넣지 않습니다. Linear의 ENG-2498 같은 번호는 중개 업무에서 쓰지 않아 뺐습니다.
