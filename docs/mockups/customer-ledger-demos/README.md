# 고객 원장 데모 4종

`index.html`을 브라우저에서 열면 네 시안을 비교할 수 있습니다. 서버나 설치 없이 동작합니다. 글꼴은 CDN에서 불러오며, 인터넷이 없으면 시스템 글꼴로 표시됩니다. 실제 앱에는 반영하지 않았습니다.

네 시안은 같은 데이터를 씁니다. 한 화면에서 저장한 상담, 일정, 담당 변경은 다른 화면에도 나타납니다. 상단의 `시안 초기화`를 누르면 처음 상태로 돌아갑니다.

## 시안

| 파일 | 시안 | 확인하려는 것 |
| --- | --- | --- |
| `a-action-ledger.html` | A 할 일 원장 (권장) | 지금 표 구조를 지키면서 기본 정렬을 다음 할 일로 바꿔도 고객을 찾기 편한가 |
| `b-inbox.html` | B 오늘 처리함 | 직원들이 일을 한 건씩 처리하는 흐름을 좋아하는가 |
| `c-sheet.html` | C 스프레드시트 | 칸을 바로 고치는 편리함이 잘못 고칠 위험보다 큰가 |
| `d-team-board.html` | D 담당자 보드 | 팀장이 일을 나누는 화면이 원장 안에 있어야 하는가, 별도여야 하는가 |

## 공통으로 적용한 규칙

- 고객은 의뢰의 대표 연락처를 기준으로 묶습니다. 업무철이라는 말은 화면에 나오지 않습니다.
- 다음 할 일은 구함의 다음 연락일과 내놓음의 다음 확인일 중 이른 값입니다.
- 부부와 가족은 합치지 않고 관계 칩으로 잇습니다. 팔고 사기 연계는 의뢰 행에 표시합니다.
- 소유자를 모르는 내놓음 의뢰는 `고객 미확인`으로 보여 주고, 연결해야 상담을 남길 수 있습니다.
- 일시중단 옵션은 숨기지 않고 흐리게 표시합니다.
- 상담을 남길 때는 어떤 의뢰에, 누구와 상담했는지 폼에 항상 보입니다. 대리인이나 공동 의뢰인이 있으면 상담 상대를 고를 수 있습니다.
- 작성 중인 내용은 의뢰별로 보관합니다. 일정 칩이나 의뢰 드롭다운으로 대상을 바꿔도 내용이 따라가지 않고, 돌아오면 되살아납니다. 쓰던 내용을 다른 의뢰로 옮기려면 복사해서 붙여 넣습니다.
- 시트를 열면 표가 옆으로 밀려서, 시트를 연 채 다른 고객을 고를 수 있습니다.

## 해볼 것

### A 할 일 원장
- 빨간 `5일 지남 확인`을 눌러 상담을 저장합니다. 고객이 해당 일정 구간으로 옮겨 갑니다. 알림의 `되돌리기`로 취소할 수 있습니다.
- `1011`로 검색합니다. 공동 의뢰인 이서연의 번호로 김민준 고객이 찾아지고 `이서연으로 찾음`이 표시됩니다.
- 김하나의 `배우자 이정호` 칩을 누르면 이정호 고객으로 이동합니다.
- `고객 미확인` 보기에서 `소유자 연결`을 누릅니다. 의뢰가 그 고객 아래로 옮겨집니다.
- `모두 접기`로 고객당 한 줄 보기를, `고객별 묶기` 끄기로 의뢰 평면 목록을 봅니다.

### B 오늘 처리함
- `C`를 누르고 내용을 적은 뒤 `⌘↵`(Windows는 `Ctrl+Enter`)로 저장합니다. 진행률이 오르고 다음 일로 넘어갑니다.
- `↑`, `↓`로 목록을 이동하고 `내 담당`, `전체`, `미배정`을 바꿔 봅니다.

### C 스프레드시트
- 칸을 누르고 방향키로 움직입니다. `Enter`나 같은 칸을 한 번 더 눌러 편집하고, `Esc`로 취소합니다.
- 담당, 상태, 다음 일정, 할 일, 메모를 바꿀 수 있습니다. 나머지 칸은 잠겨 있습니다.
- 여러 행을 체크하면 담당과 다음 일정을 한 번에 바꾸는 막대가 나타납니다.
- `묶기`를 고객, 담당, 다음 일정, 구분으로 바꿉니다. `열`에서 칸을 숨길 수 있습니다.

### D 담당자 보드
- 카드를 다른 담당자 칸으로 끌어 담당을 넘깁니다. 끄는 대신 카드 위의 담당 선택을 써도 됩니다.
- 위쪽 숫자를 눌러 지남, 오늘, 미배정 등만 봅니다.

## 시안과 실제 스키마의 차이

- 시안은 구함 조건과 내놓음 의뢰를 같은 모양의 행으로 다룹니다. 실제로는 구함이 `BuyerIntake`와 `BuyerRequirement` 두 단계이고, 담당과 다음 연락은 `BuyerRequirement`에 있습니다.
- 내놓음의 사람은 지금 `PropertyContact`에서 빌려 옵니다. 의뢰별로 사람을 정확히 보여 주려면 `ListingIntakeContact`가 필요합니다.
- 소유자 연결은 시안에서 의뢰에 바로 붙습니다. 실제로는 부동산의 관계(`PropertyContact`)를 함께 다뤄야 합니다.
- 시안의 `미배정`과 담당 이동은 사무소 권한을 확인하지 않습니다. 실제로는 역할별 권한 정책을 정해야 합니다.

## 포함하지 않은 것

의뢰 추가, 전화와 문자 발송, 매칭 후보 목록, 페이지 나눔은 넣지 않았습니다. 해당 버튼은 안내 문구만 표시합니다. 모든 이름, 번호, 메모는 가상이며 기준일은 2026년 11월 3일(화)입니다.
