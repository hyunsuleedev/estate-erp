# 에스테잇플로우 — 고풍스러운 시작 화면 3안

독립적인 Three.js 데모입니다. 기존 아파트 단지 데모와 실제 앱은 변경하지 않습니다.

```sh
cd docs/mockups/heritage-splash
npm install --ignore-scripts
npm start
```

http://127.0.0.1:8771

1. **가죽 매물 장부**: 금박 표지, 가죽 결, 종이 층. 표지를 고정된 힌지로 열어 매물대장을 표시합니다.
2. **황동 레일의 매물 카드**: 고객·계약 카드 사이에서 매물 카드 한 장이 앞으로 이동합니다.
3. **월넛과 황동 문패**: 나뭇결과 황동 판, 음각 인쇄를 표현한 로고 위로 조명이 이동합니다.

상단에서 세 디자인을 전환하고, 로그인 / 스플래시 보기를 바꿀 수 있습니다. 하단에서 구간, 재생 속도, 반복, 정지와 다시 재생을 조절합니다. 기본 재생은 6초 후 정지하며 움직임 줄이기 설정은 마지막 프레임으로 시작합니다. 탭을 벗어나면 렌더링을 멈춥니다.

재질과 인쇄는 CanvasTexture로 생성하며 외부 이미지나 CDN을 사용하지 않습니다. 카드의 매물 정보는 시안용 예시입니다. 로그인 폼은 서버로 전송하지 않습니다. 실제 앱의 시작 상태와 로그인 전환은 연결하지 않았습니다.
