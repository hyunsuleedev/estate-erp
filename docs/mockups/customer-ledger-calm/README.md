# 고객원장 디자인 시안

`index.html`을 브라우저에서 직접 열면 됩니다. 설치나 서버, 외부 라이브러리 없이 실행됩니다.

## 디자인 방향

- 고객 / 의뢰·조건 / 다음 할 일의 세 축으로 목록을 단순화했습니다.
- 고객의 내놓음·구함을 함께 표시하고 가격을 유지한 채 긴 단지명만 줄입니다.
- 녹색은 선택·내놓음, 청색은 구함, 황토색은 오늘 연락에 사용합니다.
- 흰 목록, 옅은 녹색 작업 배경, 얇은 구분선으로 정보의 위치를 구분합니다.
- 시스템 한글 서체를 사용하고, 브랜드에만 Georgia를 사용합니다.
- 상세 조건과 상담 기록은 오른쪽 패널에서 확인합니다. 좁은 화면에서는 모달 패널로 열립니다.
- 스키마 이름이나 업무철 계층은 화면에 드러내지 않습니다.

## 동작

검색, 전체/오늘 연락/내놓음/구함 필터, 담당자 필터, 정렬, 고객 상세 선택, 관심 고객 지정, 고객 추가, 상담 기록, 연락 일정 편집, 할 일 완료/취소를 사용할 수 있습니다.

변경은 해당 브라우저의 localStorage에 저장합니다. 날짜는 2026-09-15를 기준으로 한 예시이며, 고객·전화번호·매물은 가상 데이터입니다. 다른 메뉴는 주변 배치를 보여주는 정적인 시안입니다. 실제 전화 발신이나 CRM 서버 쓰기는 수행하지 않습니다.

## 확인한 내용

Ego 브라우저에서 다음 동작을 확인했습니다.

- 이름 검색, 검색 결과 없음과 초기화
- 오늘 연락 3명, 담당자 이민호 4명 필터
- 고객 상세 전환, 상담 추가와 새로고침 후 보존
- 연락 완료 시 오늘 연락 집계 감소 및 완료 취소
- 연락할 일 문구 변경
- 새 고객 추가 및 이름순 정렬
- 1440 / 1024 / 390px에서 페이지 가로 넘침 없음

이 문서는 독립 HTML 시안의 확인 결과입니다. 실제 Electron 고객원장에 통합하거나 검증한 결과가 아닙니다.
