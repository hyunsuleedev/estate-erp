# 에스테잇플로우 — 10초 시네마틱 3D 로고

사용자 요청에 맞춘 별도 10초 스플래시 시안. 기존 시안 및 실제 앱은 수정하지 않음.

- 0–2.5초: 어둠 속 금속 가장자리를 따라 조명이 드러남.
- 2.5–6초: 입체 조각 주위를 얇은 빛의 궤적과 입자가 지나감. 카메라가 정면으로 이동.
- 6–8초: 원본 SVG의 두 조각이 변형 없이 정렬·결합.
- 8–10초: 마지막 반사광이 표면을 지나고 프로그램 이름이 나타남.

Three.js, 베벨을 적용한 ExtrudeGeometry, 금속/클리어코트 재질, 절차적 스튜디오 환경 반사, bloom, 그림자. 모든 리소스는 로컬에서 제공한다. 외부 이미지·폰트·API 없음.

실행: 이 디렉터리에서 `npm install` 후 `npm start`. http://127.0.0.1:8775/

하단 도구는 시안 검수용이며 구간 확인·일시정지·재생을 지원한다. 10초 후 완성 로고에서 정지한다. 동작 줄이기 설정에서는 완성 화면으로 시작하며 탭이 숨겨지면 렌더링을 중지한다. 실제 로딩 상태와 연결하지 않은 데모다.
