# 고객 원장 — 가구 묶음 시안

`index.html`을 브라우저에서 직접 엽니다. 설치·서버·외부 라이브러리가 필요 없는 독립 HTML이며, Electron 데스크톱 고객원장 한 화면을 위한 시안입니다. 실제 앱에는 반영하지 않았습니다.

## 검토하려는 것

업무철(BrokerageCase)을 의뢰마다 필수로 저장하지 않고도 고객원장을 "한 고객의 모든 의뢰를 한눈에" 보여줄 수 있는지 확인합니다. 툴바의 **묶음 기준**으로 같은 데이터를 두 방식으로 바꿔 봅니다.

| 묶음 기준 | 규칙 | 화면 결과 |
| --- | --- | --- |
| 현재 · 업무철 | 의뢰의 본인 집합이 정확히 같을 때만 같은 업무철로 자동 연결 (`brokerage-case.resolver.ts`) | 김민준이 두 묶음에 나뉘어 나옴, 고객 없는 내놓음 3건이 빠짐, 다른 업무철의 의뢰끼리는 연계 불가 |
| 제안 · 고객 가구 | 같은 의뢰에 본인(소유자·공동소유자·매수자·공동매수자)으로 함께 오른 사람과, ‘원장에서 함께 보기’를 켠 가족 관계를 한 묶음으로 매번 계산 | 한 사람은 한 번만 나옴, 고객 미지정 의뢰가 작업 목록으로 보임 |

대리인·법무사·조언자는 묶음을 잇는 데 쓰지 않습니다. 대리인 한 명이 여러 고객을 하나로 이어 붙이지 않게 하기 위해서입니다. 시안에서는 한상우가 윤도현과 오수빈 양쪽의 대리인이지만 두 고객은 따로 표시됩니다.

## 해볼 것

- **같은 사람 두 번:** 묶음 기준을 `현재 · 업무철`로 바꾸면 김민준(혼자 명의 매도)과 김민준 +1(부부 공동 매수)이 따로 나옵니다. `제안`으로 돌아오면 한 묶음이 되고, 두 의뢰가 연계선으로 이어집니다.
- **가족 관계로 묶기:** 박정숙 이름을 눌러 상세를 열고 `함께 보기`를 켜면 아들 박지훈·예비 배우자 정하늘의 신혼집 구함이 같은 묶음으로 합쳐집니다. 이정호·김하나 부부는 배우자 관계라 기본으로 묶여 있습니다.
- **고객 미지정 의뢰:** 맨 아래 묶음에서 `소유자 연결`을 누르고 기존 연락처나 새 고객을 고르면, 그 의뢰가 해당 고객 묶음으로 옮겨집니다.
- **팔고 사기 연계:** 이정호의 내놓음 행 `⋯` 메뉴에서 김하나의 구함 전세를 고르면 두 행이 연계선으로 이어집니다. `현재 · 업무철`에서는 둘이 다른 업무철이라 연계할 수 없다는 안내가 나옵니다.
- **검색:** `1011`(이서연 번호)로 검색하면 김민준 · 이서연 묶음 하나만 나오고 `이서연 번호로 찾음` 표시와 이름 강조가 붙습니다. `한상우`로 검색하면 대리인으로 연결된 두 고객이 각각 나옵니다.
- **지난 의뢰:** 김민준 묶음의 `지난 의뢰 1건`을 펼치면 2024년 전세 계약 완료 이력이 보입니다.
- **고객별 묶기 끄기:** 같은 데이터가 의뢰 단위 평면 목록이 됩니다. 묶음이 저장값이 아니라 계산값이면 `/customers`와 `/customers-table`을 이 스위치 하나로 합칠 수 있다는 제안입니다.

## 화면 구성

- 머리줄은 가구 단위입니다. 이름(두 명까지, 나머지는 `외 N`), 첫 구성원 번호, 가구 안 가장 최근 상담과 가장 이른 다음 연락, 의뢰 담당자를 모아 표시합니다.
- 의뢰 행의 `본인` 열에 그 의뢰의 본인과 역할(소유자/공동 소유/의뢰인/공동 의뢰, 대리인)을 표시합니다. 머리줄에 여러 사람이 있으므로 행마다 누구의 의뢰인지 보여줍니다.
- 팔고 사기 연계는 두 행 사이의 보라색 선과 `연계 · 매도 잔금으로 매수` 줄로 표시합니다. 화면에 "업무철"이라는 말은 나오지 않습니다.
- 이름을 누르면 오른쪽 시트에 묶인 이유, 구성원, 관계별 `함께 보기` 스위치, 진행 의뢰, 최근 상담, 지난 의뢰가 나옵니다.
- 열 구성은 현재 `/customers`를 따르되 최소·최대 월세와 평형을 한 열씩으로 줄이고, 의뢰별 담당 열을 더했습니다.

## 예시 데이터와 범위

고객 15명, 진행 의뢰 16건(고객 미지정 3건 포함), 종결 의뢰 1건으로 시작합니다. 모든 이름·번호·매물은 가상이며 기준일은 2026-10-15입니다. 변경 내용은 `estait-ledger-household-v1` 접두사의 localStorage에만 저장하고, 하단 `시안 초기화`로 처음 상태로 돌아갑니다.

의뢰 추가, 의뢰 상세, 매칭 후보는 안내 메시지만 표시합니다. 정렬은 최근 등록순·다음 연락순·이름순만 제공하고 열 제목 정렬, 지역·가격 필터, 선택 체크박스는 생략했습니다. 서버 API·페이지 나눔·실제 Electron 동작은 포함하지 않습니다.

## 브라우저 확인

Playwright(Chromium)에서 실제 클릭·입력으로 확인했습니다.

- 1440×960: 두 묶음 기준 전환, 김민준 중복과 연계 경고(현재), 한 묶음과 연계선(제안)
- `1011` 검색 결과 1묶음 2건, 찾은 사람 표시
- 박정숙 `함께 보기` 켜기 → 박정숙 · 박지훈 외 1 묶음, 시트가 합쳐진 묶음을 따라감, 팔고 사기 3 → 4
- 고덕아르테온 201동 1502호를 정현우에게 연결 → 정현우 묶음으로 이동, 고객 미지정 3 → 2
- 이정호 내놓음 ↔ 김하나 구함 연계 생성, 연계선 표시
- 고객별 묶기 끄기/켜기, 시안 초기화
- 1024×768: 페이지 가로 넘침 없음, 표 머리와 본문이 함께 가로 스크롤(1060px)
- 콘솔 오류 없음(favicon 404 제외)
