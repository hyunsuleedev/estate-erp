# 고객 원장 표 — 매물관리 디자인 맞춤 시안

`index.html`을 브라우저에서 직접 엽니다. 서버나 설치 없이 동작합니다. 글꼴은 CDN에서 불러오며, 인터넷이 없으면 시스템 글꼴로 표시됩니다. 실제 앱에는 반영하지 않았습니다.

`/customers-table`을 매물관리 표(`property-listings-table.tsx`, `property-toolbar.tsx`)의 디자인에 맞춰 다시 구성한 시안입니다. 표는 나누지 않고 한 표로 둡니다.

## 매물관리에서 가져온 것

| 항목 | 내용 |
| --- | --- |
| 행 | 의뢰 1건을 33px 한 줄로 표시. 거래 옵션이 여러 개면 그 칸 안에 쌓음 |
| 머리글 | 36px 한 단, 12px 글자와 아이콘, 세로줄 `#eeeeec`, 아래줄 `#d8d6d0` |
| 고정 열 | 왼쪽에 선택·고객·연락처·작업 고정, 끝에 경계선 |
| 값 | 왼쪽 정렬, 빈 값은 `-`, 고객명은 14px 굵게 |
| 표시 | 거래와 상태는 매물관리와 같은 색, 상태 앞의 점, 일정은 입주가능일과 같은 모양 |
| 메모 | 둘째 줄 대신 별도 `의뢰 메모` 열, 남는 폭을 차지 |
| 툴바 | 둥근 보기 전환과 검색, `거래유형`처럼 값이 없을 때 이름만 보이는 필터, 오른쪽 `컬럼` |
| 열 접기 | 머리글 위 `+` 버튼으로 열 묶음을 접고 펼침 |

## 앱과 달라지는 것

- 지금 앱의 맥락 행과 2단 머리글을 없앱니다.
- `월세` 2열은 평소 접어 둡니다. 접으면 금액 칸에 `3,000만/80만`처럼 보증금과 월세를 함께 표시합니다. `+`를 누르면 월세 열이 나타나고 월세로 정렬할 수 있습니다.
- `+1`은 함께 연결된 사람 수입니다.
- `의뢰 추가` 버튼을 매물관리의 `새 매물 등록`과 같은 자리에 둡니다.

## 해볼 것

- 표 위 `+`로 월세 열을 펼치고 접습니다.
- `담당`, `다음 연락`, 구함의 `상태`를 눌러 바꿉니다. 금액과 메모는 두 번 눌러 고칩니다.
- `컬럼`에서 안 쓰는 열을 끕니다.
- 왼쪽 위 아이콘으로 사이드바를 접어 표 폭을 넓힙니다.

## 서버 변경

필요 없습니다. 지금 원장 API로 그대로 만들 수 있게 맞췄습니다. 그래서 다음 한계는 지금 앱과 같습니다.

- 내놓음의 담당과 다음 연락은 `-`로 표시합니다.
- 다음 연락순 정렬은 없습니다.
- 담당과 다음 연락 필터는 구함 조건에만 적용되어, 켜면 내놓음 의뢰가 빠집니다.

## 시안과 앱의 차이

- 담당과 상태가 고루 섞이도록 앞선 시안의 가상 데이터(고객 19명, 의뢰 22건)를 씁니다. 기준일은 2026년 11월 3일(화)입니다.
- 지역·단지 선택과 `+ 필터`, 의뢰 추가, 화면 이동은 안내 문구만 표시합니다. 표 안의 ⋮ 메뉴도 같습니다.
- 매물관리의 방향키 칸 이동과 열 폭 조절은 넣지 않았습니다.
- 매칭 패널은 건수와 단계만 보여 줍니다. 앱에서는 지금의 매칭 패널이 그대로 들어갑니다.
- 변경 내용은 `estait-table-property-style-v1` 키로 이 브라우저에만 저장합니다. `시안 데이터 초기화`로 되돌립니다.
