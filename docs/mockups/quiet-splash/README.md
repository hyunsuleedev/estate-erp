# 에스테잇플로우 — 조용한 시작

기존 데모를 보존한 별도 스플래시 시안. 외부 패키지 없이 SVG/CSS로 구현.

아이보리 배경 위에 원본 로고의 두 조각이 7px씩 벌어져 대기한다. 중앙의 가는 선만 조용히 반복된다. 준비 완료 시 420ms 동안 맞물린 뒤 로그인 미리보기로 전환한다. 동작 줄이기 설정에서는 반복 및 전환 모션을 생략한다.

실행: `python3 -m http.server 8774 --bind 127.0.0.1 --directory docs/mockups/quiet-splash`

- 기본 데모 준비 시간: 1.6초. 하단 ‘로딩 유지’와 ‘준비 완료’로 임의의 대기 시간을 확인할 수 있다.
- `window.splashPreview.start(readyPromise)`는 실제 준비 Promise에 맞춰 완료하며 최소 대기 시간을 강제하지 않는다.
- 하단 버튼은 시안 검수용이다. 제품 연결 시 제거한다.
- 실제 앱, 로그인, 데이터베이스와 연결되지 않았다.
