# 관리단지 사이드바 시안

`index.html`을 브라우저에서 직접 열면 됩니다. 설치나 서버, 외부 라이브러리 없이 실행됩니다.

## 방향

단지 목록을 늘 펼쳐 두지 않습니다. 본문 첫 줄의 **단지 버튼**(지금 단지 이름)을 누르면 앱 메뉴와 본문 사이에 단지 사이드바가 밀고 들어오며 열립니다. 팝업처럼 본문 위에 겹치지 않고 자리를 차지하는 사이드바입니다. 사용자가 직접 열고 닫는 영역이라 패널이라는 것이 분명하고, 단지가 많아도 목록 높이를 다 쓸 수 있습니다.

- 열기·닫기: 단지 버튼, 사이드바 머리줄의 닫기 버튼, `[` 키를 씁니다. 검색창에서 `Esc`를 누르면 검색어를 먼저 지우고, 검색어가 없으면 사이드바를 닫습니다.
- 열면 검색창에 바로 커서가 갑니다. `↓`로 목록에 들어가고 `Enter`로 첫 결과를 엽니다.
- 열림 상태와 너비는 기억합니다. 너비는 오른쪽 경계를 끌어 220~380px 사이로 바꿀 수 있습니다.
- 닫혀 있을 때 단지 버튼에 "단지 12"가 붙어, 이 버튼이 목록으로 이어진다는 것을 알려 줍니다.
- 위쪽 띠의 "단지 고르면 사이드바 닫기"로, 단지를 고른 뒤 자동으로 닫는 동작도 비교할 수 있습니다. 기본은 열린 채로 둡니다.
- 사이드바를 열어도 본문에는 최소 700px을 남깁니다.
  - 창이 좁으면 저장된 너비보다 사이드바를 줄여서 엽니다. 끌어서 넓힐 때도 이 한도까지만 넓어집니다.
  - 본문이 880px 이하가 되면 "동·호수 추가"를 아이콘만 남깁니다.
  - 780px 이하가 되면 보기 방식 이름을 줄입니다(호수 목록 → 목록 등).
  - 단지 이름이 길면 단지 버튼의 이름이 먼저 줄어들며 말줄임됩니다(최소 120px). 전체 이름은 버튼 툴팁에 나옵니다.
  - 이렇게 해서 앱 최소 폭인 1180px 창에서도, 긴 단지명을 골라도 도구줄이 화면 밖으로 밀리지 않습니다.
- 실제 구현에서는 처음 들어와 고른 단지가 없을 때 사이드바를 열어 둡니다.

## 단지 목록

- 고정한 단지는 맨 위에 둡니다.
- 관리호수가 없는 단지는 맨 아래 "기록 없는 단지" 묶음으로 모으고, 처음에는 접어 둡니다. 검색 중이거나 지금 연 단지가 그 묶음에 있으면 펼칩니다.
- 보기 메뉴에서 동네별·유형별로 묶을 수 있습니다.
- 단지가 6개 이하면 검색줄을 숨깁니다.
- 마우스를 올리면 규모와 준공년도가 나옵니다.
- 사이드바 머리줄과 검색줄 높이를 본문 두 도구줄과 맞춰 가로선이 이어지게 했습니다.

## 데이터

- "매물·만기 표시"는 단지별 진행 매물 수와 만기 임박 세입자 수입니다. 지금 API에는 없어 서버 집계가 필요합니다.
- 관리호수 수는 현재 `GET /office-sites` 응답의 `site._count.properties`로 바로 쓸 수 있습니다.
- 단지·호실·연락처는 가상 데이터입니다. 열림·고정·묶기·너비만 브라우저 localStorage에 저장하며, 서버에는 쓰지 않습니다.
