매물관리 상단 툴바 — 시안 v1

1행은 찾기(거래유형 · 위치 · 키워드), 2행은 좁히기(조건 필터 + 표 설정)로 역할을 나눴습니다. 표 영역은 맥락을 보여 주려고 넣은 것이고 바뀌지 않습니다.
근거 자료: CRM 툴바 리서치 보고서 (HubSpot · Linear · Stripe · Attio · Airtable · Notion)

필터는 4개만 늘 보이게매물상태 · 가격 · 공급평형 · 방/욕실. 나머지는 "+ 필터"로 넣고, 값을 고르면 칩으로 나타납니다. (HubSpot 빠른 필터)
"전체"를 쓰지 않음설정 전 칩은 라벨만, 설정된 칩만 값과 ×를 보여서 걸린 필터가 바로 보입니다. (Stripe 필터 칩)
컨트롤 모양은 한 가지1행은 회색 채움(muted) 하나로 맞추고, 진한 색은 "새 매물 등록"에만 씁니다. 초기화 · 컬럼은 오른쪽에 고정합니다.
현재

지금 화면

1,500px 창에서 캡처

  • 2행 칩 9개가 모두 "전체"를 표시해서 어떤 필터가 걸렸는지 구분하기 어렵고, 오른쪽 끝 컬럼 · 초기화가 화면 밖으로 밀려나 있습니다.
  • 동 · 호는 placeholder만 있어서 값을 입력하면 라벨이 사라집니다. 1행 컨트롤 모양이 4가지 섞여 있습니다.
A

기본 상태

직접 눌러 보세요: 탭 전환, 동·호 입력, 위치 선택, 칩 클릭(예시 값이 들어감), "+ 필터", / 키

  • 거래유형 탭에 건수를 붙이고, 탭을 바꾸면 2행 가격 칩이 바뀝니다: 매매 → "매매가", 전세 → "전세가", 월세 → "보증금" + "월세".
  • 위치는 한 덩어리로 묶었습니다: [지역·단지 ▾ │ 동 │ 호]. 동·호는 입력값 뒤에 단위가 붙어 101동 3401호처럼 주소로 읽힙니다. 2행에 있던 지역은 위치 팝오버로 옮겼습니다.
  • 검색창은 남는 폭을 채우고(최대 420px), /로 바로 포커스합니다.
B

필터를 건 상태

매매 탭 · 고덕그라시움 101동 3401호 · 거래중 · 15억~25억 · 광고 중

  • 매매 탭이라 "월세" 칩이 없고, 가격 칩 이름이 매매가입니다.
  • "+ 필터"에서 고른 광고는 값이 생긴 뒤에만 칩으로 나타납니다. 위치 그룹의 × 하나로 지역·단지·동·호를 한 번에 지웁니다.
  • 초기화는 필터가 하나라도 있을 때만 나타나고, 오른쪽에 고정되어 2행이 넘쳐도 가려지지 않습니다.
C

위치 팝오버

지역으로 좁힌 뒤 단지를 고르는 일을 한곳에서

  • 위에서 시도 · 시군구 · 법정동을 고르면 아래 단지 목록이 그 지역으로 좁혀집니다. 관리단지가 먼저 나오고 단지별 매물 수가 보입니다.
  • 단지를 고르지 않고 닫으면 지역만 적용되고, 트리거에 "강동구"처럼 지역 이름이 표시됩니다.
D

"+ 필터" 메뉴 · 월세 탭

자주 쓰지 않는 필터는 메뉴 안으로

  • 월세 탭에서는 보증금 · 월세가 빠른 필터가 됩니다. 유형 · 입주일 · 광고는 메뉴 안에 있고, 이미 설정된 값은 메뉴 오른쪽에 표시됩니다.
  • 어떤 필터를 늘 보이게 할지는 실제 사용 빈도로 정해야 합니다. 지금은 코드의 tier 값(월세 · 입주일 = 3)을 기준으로 골랐습니다.
