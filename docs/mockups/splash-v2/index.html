스플래시 시안 2판

절제된 움직임과 정밀한 선으로 전문적인 인상을 주는 아홉 가지 방향입니다. 바탕은 모두 흰색입니다. 모두 앱이 준비되는 즉시 끝나고, 준비 과정을 글자로 알려 줍니다. 카드를 누르면 로딩 시간과 도착 화면을 바꿔 가며 볼 수 있습니다.

  • 지금은 매번 9초를 봅니다앱이 먼저 준비돼도 아파트 → 도면 → 로고 재생이 끝날 때까지 기다립니다.
  • 3D 장면이 미완성 모형처럼 보입니다재질 없는 옅은 덩어리라 대비가 낮습니다.
  • 무엇을 하는 중인지 알 수 없습니다64px 막대 하나뿐이고 진행 단계나 지연 안내가 없습니다.

새로 추가한 시안

9신축 단지 3D

실제 주동 구조(2세대 1코어 판상형, Y자형 탑상형)와 배치도를 따른 3D 단지입니다. 타워크레인과 함께 층이 올라가고 완공되면 옥상이 얹힙니다.

최소 3초 · Three.js 사용(지금 앱에 이미 있음)

8신축 단지

타워형과 판상형이 섞인 신축 단지가 입체로 한 층씩 올라가고, 카메라가 천천히 돕니다. 완공되면 옥상 구조물이 붙습니다.

최소 2.6초 · 화면 교체만으로 적용

6올라가는 로고

로고가 지붕이 되어 진행률만큼 층이 쌓여 올라가고, 준비되면 다시 로고로 내려앉아 가운데 창으로 앱에 들어갑니다.

최소 1.9초 · 화면 교체만으로 적용

7제자리로

선으로 그려진 로고가 다음 화면의 로고 자리로 옮겨 앉고, 화면이 그 주위로 채워집니다.

최소 1.6초 · 화면 교체만으로 적용

앞서 만든 시안

1로고 창

로고 두 조각이 맞물리고, 가운데 창이 커지면서 그 안으로 앱이 드러납니다.

최소 1.1초 · 화면 교체만으로 적용

2시그니처

로고를 가는 선으로 그린 뒤 면을 채웁니다. 실선 진행 표시와 버전 표기가 있습니다.

최소 1.9초 · 화면 교체만으로 적용

3입면도

모눈 위에 단지 입면이 한 층씩 올라가고 층수 눈금이 따라 올라갑니다. 진행률이 곧 그림입니다.

최소 1.7초 · 화면 교체만으로 적용

4흐름 한 줄

매물 → 고객 → 매칭 → 계약을 선 하나가 이어 가고, 끝나면 로고로 모입니다.

최소 1.5초 · 화면 교체만으로 적용

5오늘의 브리핑

기다리는 동안 오늘 일정, 확인 필요 매물, 이번 주 잔금을 먼저 보여 줍니다.

최소 1.7초 · 요약 값을 주는 서버 응답이 필요
