# 아파트 정보 → 로고 수렴 데모

```sh
cd docs/mockups/information-splash
npm install --ignore-scripts
npm start
```

http://127.0.0.1:8773

1. 아파트 단지에 매물 설명 박스가 연결됩니다.
2. 매물·고객·상담·계약 등 시안용 정보가 16개까지 늘어납니다.
3. 제공된 로고의 두 조각이 양옆에서 등장합니다. 박스들이 중심으로 이동하고 연결선이 사라집니다.
4. 정보 카드가 정리된 뒤 정확한 원본 로고와 프로그램명이 남습니다.

건물의 위치·높이·회전은 고정됩니다. Three.js는 3D 단지를, HTML/SVG는 매물 카드와 연결선, 로고를 담당합니다. 실제 지붕 위치를 화면에 투영해 연결선을 붙입니다. 모든 상태는 하나의 10초 타임라인으로 계산하므로 구간 이동과 반복 시 같은 결과를 보여줍니다.

기본 스플래시 보기이며 로그인 보기로 전환할 수 있습니다. 재생, 일시정지, 속도, 반복, 구간 선택을 지원합니다. 움직임 줄이기 설정에서는 최종 로고로 시작합니다. 정착 후와 숨겨진 탭에서는 지속적으로 렌더링하지 않습니다.

기존 데모는 수정하지 않았습니다. 실제 앱·인증·매물 데이터에는 연결하지 않았으며 화면의 모든 매물 정보는 시안용 예시입니다.
