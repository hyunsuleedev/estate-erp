Estate ERP를 위한
세 가지 슬릭 UI 방향

기존의 베이지 사이드바, 파란색 대형 버튼, 중첩 카드 구조를 걷어내고 Linear·Notion·Attio의 장점을 부동산 중개 업무 밀도에 맞게 재구성했습니다. 이미지를 누르면 1586 × 992 원본으로 확대됩니다.

OPTION 01

Balanced Data Workspace

Linear의 선명함과 Attio의 레코드 구조를 가장 안전하게 결합한 기본형

익숙한 단일 사이드바를 유지하면서 색과 외곽선을 크게 줄였습니다. 현재 정보 구조에서 전환 비용이 가장 낮습니다.

구조

슬림 단일 사이드바, 텍스트 탭, 평면 테이블, 380px 우측 인스펙터로 구성합니다.

강점

기존 사용자의 학습 부담이 낮고 매물·고객·거래 페이지 전반에 일관되게 확장하기 쉽습니다.

고려할 점

가장 안정적인 만큼 3번보다 구조적 개성이 덜하고 초고밀도 업무에서는 좌측 공간 효율이 낮습니다.

OPTION 02

Quiet Paper Workspace

Notion의 조용한 문서 감각과 Attio의 데이터베이스를 결합한 편집형

헤더와 도구를 최소화하고 여백을 늘려 장시간 사용 시 피로를 줄입니다. 기록과 맥락을 읽는 화면에 특히 적합합니다.

구조

페이지형 타이틀, 비상자형 툴바, 평면 데이터베이스, 자연스럽게 연결되는 사이드 피크를 사용합니다.

강점

가장 차분하고 프리미엄한 인상이며 상담 기록, 계약서, 고객 상세처럼 읽기 중심 화면에 강합니다.

고려할 점

여백을 확보한 만큼 작은 노트북에서 동시에 보이는 행 수가 줄어들 수 있습니다.

OPTION 03

Compact Command Workspace

Linear의 작업 속도와 이중 내비게이션을 가장 적극적으로 적용한 고밀도형

아이콘 레일과 업무별 보조 레일을 분리해 39개 페이지를 빠르게 전환합니다. 숙련된 실무자의 반복 작업에 초점을 둡니다.

구조

56px 글로벌 아이콘 레일, 154px 업무 내비게이션, 명령 검색, 고밀도 테이블과 작업 패널을 사용합니다.

강점

세 안 중 가장 빠르고 현대적이며 페이지 수가 늘어날수록 내비게이션 확장성이 좋습니다.

고려할 점

이중 내비게이션 개념을 처음 접하는 사용자에게 짧은 온보딩이 필요합니다.
